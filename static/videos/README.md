# Videos

Place optimized MP4 files here.

## Recommended

| File | Used on | Notes |
|------|---------|--------|
| `showroom.mp4` | Home hero, Gallery | H.264, ~720p–1080p, muted-friendly, under ~5–8 MB if possible |

The site already references `/static/videos/showroom.mp4`.  
Until this file exists, the hero shows the poster image and gallery video players show their posters.

### Export tips

- Format: MP4 (H.264 + AAC)
- Resolution: 1280×720 or 1920×1080
- Remove audio or keep very quiet (hero autoplays muted)
- Consider a WebM alternative later for smaller sizes
