# Uploads

Files uploaded from the **Admin panel** are stored here:

| Folder | Contents |
|--------|----------|
| `tiles/` | Tile product images |
| `videos/` | Collection videos (homepage mid-section) |
| `posters/` | Optional video poster images |

Served publicly at `/static/uploads/...`.

Do not place source brand assets here — use `assets/` for originals.
